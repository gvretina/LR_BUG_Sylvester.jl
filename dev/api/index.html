LR_BUG_Sylvester.LR_BUG_Sylvester — Module
LR_BUG_Sylvester

Code for the numerical experiments of "A Low-Rank BUG Method for Sylvester-Type Equations": the rank-adaptive BUG method (matrix and Tucker) and the two rational Krylov methods it is compared with (RKSM, Casulli-Robol; TBRK, Casulli), on the paper's test problems.

Every solver allocates all its memory when it is constructed; solve! allocates nothing.

LR_BUG_Sylvester.BlockKrylovKStep — Method
BlockKrylovKStep(A, C; rmax, rtol, Kmax = min(n, 64·size(C, 2)))

K-steps A K + K Mᵀ = R with R ∈ span(C): Galerkin on Q = basis of Km(A, C), (QᵀAQ) Y + Y Mᵀ = QᵀR, K = Q Y. The residual of that solution is ‖Γ Y‖F ((I − QQᵀ) A Q = Z Γ: only the newest block sticks out), and the basis grows by one block while it exceeds rtol ‖R‖_F. Rebuilt at the start of every BUG solve (reset!).

LR_BUG_Sylvester.convdiff_1d — Method

1-D convection-diffusion operator, central differences on the grid points t: A = −ν·tridiag(−1, 2, −1)/h² + diag(w(t))·tridiag(−1, 0, 1)/(2h). Returns (A, (λmin, λmax)). Its off-diagonals ν/h² ± wᵢ/(2h) are positive (|w| h < 2ν), so a diagonal similarity turns A into the symmetric tridiagonal S with off-diagonals √(Aᵢ,ᵢ₊₁ Aᵢ₊₁,ᵢ): the eigenvalues are real and are computed from S (to rounding). That similarity has condition number ≈ exp(∫ w / 2ν): for small ν, A is far from normal.

LR_BUG_Sylvester.factor_reference — Method

Low-rank factors of the exact matrix solution, X ≈ U diag(σ[1:k]) Vᵀ, so that it can be stored and used without the dense n × n matrix. Randomised SVD (range finder with power subspace iterations, Halko-Martinsson-Tropp): exact to rounding because σ decays far below eps·σ₁ within the first K values. Returns σ : the leading K singular values, tail : ‖X − (best rank-K approximation)‖F, i.e. the ℓ² norm of all the others, U, V : the singular vectors up to the smallest rank k with ‖σ{k+1:end}‖₂ ≤ cutoff·‖X‖_F (beyond k the reference itself is rounding noise; see its residual).

LR_BUG_Sylvester.reciprocal_basis — Method

Orthonormal basis of the column space of every unfolding of F = 1/(1 + x₁ + ... + xd) on the uniform grid t^d (d = 2, 3; the same for every mode, F is symmetric), truncated as in both reference codes: singular values ≥ 1e-10. F is not formed: a column of Mat₁(F) is the vector 1/(1 + t + s), s = the sum of the other d − 1 coordinates, which takes the values sm = (m − 1)h, each for multm grid points. So Mat₁(F) Mat₁(F)ᵀ = K W Kᵀ with Kim = 1/(1 + ti + sm), W = diag(mult), and the basis is the leading left singular vectors of K W^{1/2}.

source
LR_BUG_Sylvester.reciprocal_core — Method

Core G = F ×ᵢ Uᵀ of F = 1/(1 + x + y + z) on t³ (t uniform), without forming F: Fijk = K{i,m} with m = j + k − 1 and Kim = 1/(1 + ti + (m − 1)h), so Gabc = Σi Uia Σm Kim Vmbc with Vmbc = Σ{j+k−1=m} Ujb Ukc (a convolution of two basis columns): O(r² n²) instead of O(n³).

LR_BUG_Sylvester.reference_convdiff — Method

Convection-diffusion (2-D), from the structure: A X + X Bᵀ = C is one big K-step (Section 3.2 of the Linear solves page of the docs) with the diffusive, symmetric tridiagonal B = Q M Qᵀ (LAPACK's tridiagonal eigensolver, Q orthogonal). X̃ = X Q solves A X̃ + X̃ M = C Q, column by column (A + μⱼ I) x̃ⱼ = (CQ)ⱼ: n tridiagonal LU solves (BandedLU). Then X = X̃ Qᵀ. Orthogonal transformations and backward-stable solves only: no inverse, no refinement.

LR_BUG_Sylvester.solve_core! — Method

Y (flat, dims d) = solution of Y ×₁ H[1] + ⋯ + Y ×N H[N] = C (flat). Symmetric Hᵢ = Eᵢ Λᵢ Eᵢᵀ: Y = (C ×ᵢ Eᵢᵀ ./ (λ₁ + ⋯ + λN)) ×ᵢ Eᵢ. General Hᵢ = Qᵢ Tᵢ Qᵢᴴ (complex Schur): C̃ = C ×ᵢ Qᵢᴴ, back-substitution over the triangular Tᵢ, Y = Re(Ỹ ×ᵢ Qᵢ).

LR_BUG_Sylvester.solve_sylvester! — Method
solve_sylvester!(ws, S, A, B, C) -> S

S = solution of A S + S Bᵀ = C (A: p × p, B: q × q, C: p × q; A, B, C are not modified). Real Schur forms of A and B, LAPACK's trsyl on the transformed (triangular) equation, then one refinement step S += solve(C − A S − S Bᵀ): the projected matrices are formed in floating point (e.g. UᵀAU), so they are slightly non-normal and plain Bartels-Stewart can lose digits in the smooth modes; one step restores full accuracy.

LR_BUG_Sylvester.stickout! — Method
stickout!(kb, J) -> Γ

The part of A·U outside span(U). Only the columns J have images leaving the space (RKSM / TBRK: the starting block; polynomial Krylov: the newest block), so (I − UUᵀ) A U = Z Γ with Z = orth((I − UUᵀ) A U[:, J]) and Γ = Zᵀ A U (|J| × K). The Galerkin residual of a projected solution Y is then ‖Γ Y‖ per side.

LR_BUG_Sylvester.triangular_backsubstitution! — Method

In place: solve Σᵢ Y ×ᵢ Tᵢ = Y for upper-triangular Tᵢ (Y flat, dims d). Recursive, as Casulli's laplace_tri: split the largest mode i of the current block I into a lower part lo and an upper part hi; the hi indices of mode i couple only among themselves, so solve that block first, then remove its coupling from the lo block (Ylo −= Yhi ×ᵢ Tᵢ[lo, hi], matrix products), then solve the lo block. Blocks with all sides ≤ nmin (26 for N = 3, as in laplace_tri) are solved entry by entry (backsubstitution!).
